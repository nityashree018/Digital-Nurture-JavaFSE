# Oracle SQL & PL/SQL Hands-on

This folder contains Oracle SQL and PL/SQL programs completed as part of the Cognizant Digital Nurture 5.0 Java FSE training.

## Topics Covered

- Creating Employee Table
- Insert Statements
- IF Statements
- Loops
- Exception Handling
- Records
- Cursors
- Dynamic SQL
- Savepoints & Rollback
- Sequences
- Triggers
- Procedures
- Functions
- Packages

## Software Used

- Oracle Database XE
- Oracle SQL Developer
